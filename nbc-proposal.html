Northcote Baptist Church · 网站改造提案

一个多语言的门，一间多语言的教会

nbc.org.nz 目前是全英文站点。这份提案基于对现网源码的实际勘察，给出三件事： 分层的多语言方案、只改子主题的 UI 改进，以及一个已经做好、可直接粘贴上线的多语言在线圣经。 原则是最小改动——不换主题、不重做站点、不碰父主题一行代码。

先说三个必须先解决的前提

为什么这决定了整个方案

子主题为空，意味着 CSS 与 functions.php 里的每一行都是我们自己写的， 父主题将来更新不会冲掉任何东西。所以本提案的 UI 部分不需要改主题、不需要买新主题、不需要重做站点， 只往一个目前空白的文件夹里加代码。

提案一

多语言：不要一次翻译整站

教会自我描述是 “intergenerational, multicultural”，并且常年开着 Kay's English Class（ESOL 英语班）。这两件事直接告诉我们目标语言是谁： 华人家庭、韩国家庭、菲律宾家庭，以及作为新西兰官方语言的 Te Reo Māori。

但把 40 多个页面全部翻成 4 种语言，是一个志愿者团队维护不下去的承诺—— 翻译会过期，过期的翻译比没有翻译更伤信任。建议分三层推进，每一层都能独立上线并产生价值。

第 1 层 · 落地页

每种语言一个页面

约 1 天 · 0 插件 · 0 成本

新建 /zh/、/ko/、/mi/ 三个普通 WordPress 页面，各写一页母语内容：

  • 我们是谁（3 句话）
  • 主日几点、地址与地图
  • 孩子来了怎么安排
  • 会说这门语言的同工与联系方式
  • 一个报名／联系表单
第 2 层 · 核心页

Polylang 翻译 8 个页面

约 1–2 周 · 免费版够用

只翻 Home、Who We Are、On Sunday、Kids、Contact、Give、Kay's English Class、Events。 其余页面自动回落英文。

  • 真实的 /zh/ 路径与 hreflang，能被搜索收录
  • 菜单可分语言配置
  • 免费版语言数量不限（TranslatePress 免费版只给 1 种额外语言，这里不合适）
第 3 层 · 长尾

机器翻译兜底

按需 · 可随时叫停

剩余页面用机器翻译层覆盖，并明确标注 “机器翻译”。 核心页永远保持人工翻译，两者不要混在一起而不作区分。

语言切换器怎么放

  • 放在顶栏右侧，与 GIVE 同一水平线——第一次来的人不会去页尾找。
  • 用语言自己的写法标注：中文 / 한국어 / Te Reo Māori / English。看不懂英文的人，正是需要切换的人。
  • 不要用国旗。国旗代表国家不代表语言，中文尤其敏感；奥克兰的华人来自多个地区。
  • 切换语言后停在对应页面，没有译文时才回首页，并提示 “此页暂无中文版”。

真正的杀手级功能不是“翻译整站”，是“双语并排”

因为教会本来就在教英文。ESOL 学员需要的不是一个纯中文站，而是 中英对照——这既服务语言学习，也服务那些英文够用但读经文吃力的人。 同样的逻辑用在讲道上：与其花大力气翻译整篇讲道稿，不如在每篇讲道下面加一段 中文／韩文摘要 + 3 条要点 + 经文出处，成本低一个数量级，实际帮助更大。

提案二

UI：全部写进子主题，一行不碰父主题

现有配色其实是可用的——砖红 #d14f42、石板蓝 #216ea3、深灰 #3b3d4a， 配 Fjalla One 标题 + Crimson Text 正文，是一套完整的视觉系统。 问题不在配色，在结构和密度。下面按投入产出排序。

1. 把首页轮播换成一个静态“门口”

第一次找教会的人只想知道四件事：几点、在哪、孩子怎么办、我该穿什么。 轮播图会把这四件事轮走。改成一屏固定内容：一张真实的会众照片、一行 “主日 10:00 · Hillcrest”、一个主按钮 “第一次来？看这里”。 顺带把 LayerSlider + GreenSock（约 200 KB）从全站移除。

2. 新建一个 “Planning your first visit” 页面

这是教会网站上被点击最多、而 NBC 目前没有的页面。内容就是上面那四个问题的回答， 再加停车、迟到了怎么办、聚会多长时间。这一页应该是第一批被翻译的。

3. 正文排版：为“跨代”会众放大

Crimson Text 在主题默认字号下偏小，对年长会友不友好。子主题里几行 CSS 即可： 

/* my-religion-child/style.css */
.entry-content, .cmsmasters_text {
  font-size: 18px;
  line-height: 1.75;
  max-width: 68ch;          /* 控制每行字数，长行最难读 */
}
.entry-content p { margin-bottom: 1.15em; }

/* 正文灰 #71727f 在白底上对比度约 4.4:1，压线；调深一档 */
body, .entry-content { color: #5c5d69; }

4. 移动端底部常驻条

手机上常驻三个入口：主日时间 · 地图导航 · 奉献。 子主题 functions.php 里输出一段 HTML，再配 30 行 CSS，是投入产出比最高的一处改动。

5. 按页卸载用不到的脚本

// my-religion-child/functions.php
add_action('wp_enqueue_scripts', function () {
    if (is_front_page()) return;          // 首页保留

    // 只有课表页需要 timetable 全家桶
    if (!is_page('our-calendar')) {
        wp_dequeue_script('timetable-carouFredSel');
        wp_dequeue_script('timetable-qtip');
        wp_dequeue_style('timetable-qtip');
    }
    // Instagram feed 只在特定页面用
    if (!is_page(['community', 'youth'])) {
        wp_dequeue_style('sbi-styles');
    }
}, 100);

先在 staging 环境逐条验证，每卸一条就回归一次；句柄名以实际 wp_print_scripts 输出为准。

6. 给 Google 一段结构化数据

约 20 行 JSON-LD，能让 Google 在搜索结果里直接显示主日时间和地址—— 本地搜索场景下这是最划算的一次改动。 

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Church",
  "name": "Northcote Baptist Church",
  "url": "https://nbc.org.nz/",
  "address": { "@type": "PostalAddress",
    "addressLocality": "Hillcrest", "addressRegion": "Auckland",
    "addressCountry": "NZ" },
  "knowsLanguage": ["en", "zh-Hans", "ko", "mi"],
  "event": { "@type": "Event", "name": "Sunday Service",
    "startDate": "2026-08-16T10:00+12:00",
    "eventSchedule": { "@type": "Schedule",
      "byDay": "https://schema.org/Sunday", "startTime": "10:00" } }
}
</script>

地址与坐标请填实际值后再上线。

提案三 · 已完成

在线圣经：一个 HTML 区块，零插件

这一部分我已经做好了。它是一个 22 KB 的自包含 HTML 片段， 在 WordPress 后台新建页面 → 插入 “自定义 HTML” 区块 → 整段粘贴 → 发布，就完成了。 不装插件、不改主题、不需要构建工具。 配色与字体直接取自现有主题（#d14f42 / #216ea3 / Fjalla One / Crimson Text）， 放上去就像是网站原生的一部分。

nbc.org.nz/bible/

Scripture text served by getBible API ·

↑ 可直接操作。此处为离线演示，内置诗篇 23 篇与约翰福音 3 章共 7 个译本； 切换到其他书卷会提示演示范围。正式版本实时连接 getBible API，全本 66 卷、117 个译本均可用。

它解决了什么

  • 双语并排——左中文右英文、或左英文右毛利文。这是给 ESOL 班和跨代家庭真正用得上的功能，而不是一个装饰性的读经器。
  • Te Paipera Tapu（毛利文圣经）——教会的价值观本来就用 Aroha / Whanaungatanga / Manaakitanga / Pono 四个毛利词表达，圣经也能读毛利文，这是一致的。
  • 界面本身四语——English / 中文 / 한국어 / Te Reo Māori 切换，按钮和标签一起变。
  • A− / A+ 字号调节，为年长会友；← → 方向键翻章；点击经节一键复制；自动记住上次读到哪里。
  • 可深链：/bible/?ref=43.3 直接打开约翰福音第 3 章——讲道页、周报、群里发链接都能用。

数据来源与版权

数据源是 getBible API v2： 免费、无需 API key、Access-Control-Allow-Origin: *（浏览器可直连）， 收录 117 个译本，均为公有领域或可自由分发的版本。已实测可用的相关译本：

  • 中文：和合本简体 cus / 和合本繁體 cut / 新译本 cns、cnt / 文理和合 chiunl
  • 한국어：korean、koreankjv
  • Te Reo Māori：maori（Te Paipera Tapu）
  • Tagalog tagalog、日本語 japkougo、Tiếng Việt vietnamese、Español valera
  • English：KJV、World English Bible、Basic English（易读版，适合 ESOL）

版权提醒

NIV、ESV、NLT、和合本修订版、새번역 等属于受版权保护的译本， 不能自行抓取或托管。如果教会希望使用 NIV，正确做法是跳转到 BibleGateway / YouVersion， 或向 API.Bible 申请授权。上面列出的译本没有这个问题。

尚未覆盖的语言

getBible 目前没有 Samoan、Tongan、Hindi 译本。若这些群体在会众中占比不小， 可对这几种语言退化为跳转 bible.com 的外链，界面上保持同一个入口。

提案四

另外几件值得做的事

讲道变成播客

现有 Sermons 已经有音频结构，加一个 RSS 输出就能进 Apple Podcasts / Spotify。 再用 Whisper 自动转写，把摘要翻成中文／韩文挂在页面上—— 对听力跟不上英文讲道的会友，这比任何界面改动都有用。

奉献页优先翻译

GIVE 已经在主导航里。银行账号、参考编号怎么填、能否开税务收据—— 这些细节恰恰是语言不通时最容易出错、也最让人尴尬的地方。银行信息做成可一键复制。

Connect Card 多语版

站上已装 Contact Form 7，直接复制出中／韩／毛利文版本即可，无需新插件。

先建 staging，再动生产环境

WordPress 6.4.9 与随主题捆绑的 LayerSlider 6.8.2 都需要一次安全检查。 建议顺序是：整站备份 → 克隆一份 staging → 所有改动先在 staging 验证 → 再上生产。 同时打开 WordPress 自动小版本更新。

把毛利文用得更实一点

现在只有四个价值观词是毛利文。作为新西兰官方语言，在导航、问候语、 主日流程里更实质地使用 Te Reo，既是文化上的正确，也是这间教会区别于其他教会的地方。

执行顺序

四周路线图

排序原则：先做零风险、不依赖插件、不动现有页面的事；把需要改动内容和装插件的事放后面。

第 1 周

零风险快赢

  • 上线在线圣经页面（粘贴 HTML 区块即可）
  • 建 /zh/、/ko/、/mi/ 三个母语落地页
  • 补全首页 15 张图的 alt 文本
  • 加 schema.org JSON-LD
  • 整站备份 + staging 环境
第 2–3 周

拆掉图片里的文字，收拾排版

  • 把 Vision / Mission / Values 与信经重排为真正的 HTML 文本（多语言的前提）
  • 修正标题层级，给首页一个真的 h1
  • 子主题 CSS：字号、行距、行宽、对比度
  • 新建 “第一次来？” 页面，首页轮播换静态首屏
第 4 周起

正式多语言与性能

  • 装 Polylang，翻译 8 个核心页面
  • 顶栏语言切换器 + hreflang
  • 按页卸载脚本，加缓存插件
  • 讲道播客 RSS + 中／韩文摘要
